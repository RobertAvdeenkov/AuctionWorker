Веб-приложения для проведения аукционов.
В проекте участвуют кеширование и 3 воркера(main, retry, DLX) для отправки сообщений в ТГ.

## Функции
1. Проведение аукциона до конкретной даты
2. Анти-снайпинг(если ставка была принята за минуту до закрытия аукциона, то он продлевается на 1 минуту)
3. Получение уведомлений через встроенный почтовый ящик и ТГ бота
4. Синхронизация ставок(с помощью особого класса)
5. Rate Limiting на все эндпоинты(кроме эндпоинта для установки ставки)
6. CRUD для аукционов
7. Кеширование главной, почтового ящика и выигранных аукционов

## Стек
1. FastAPI
2. Uvicorn
3. Bcrypt
4. Aio_pika
5. Pytest
6. SQLAlchemy[asyncio]
7. Aiogram
8. Prometheus + Grafana
9. Redis
10. WebSockets

## Запуск
1. Скачайте файлы репозитория
2. Установите библиотеки: **pip install --no-cache-dir -r requirements.txt**
3. Запуск: **docker-compose up --build**
